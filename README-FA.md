# ساخت APK «خانه‌یاب» با GitHub

GitHub برنامه را می‌سازد، امضا می‌کند و فایل APK را به تو می‌دهد؛ نیازی به Android Studio و کلید و Secret نیست.

## یک‌بار آماده‌سازی
1. در **github.com** یک مخزن **Private** (خصوصی) بساز، اسمش `khaneyab`.
2. ZIP را Extract کن. **همه‌ی فایل‌ها و پوشه‌های داخلش** را با کشیدن و رها کردن در مخزن آپلود کن (**uploading an existing file**) ← **Commit changes**.
3. فایل اتوماسیون را بساز (چون پوشه‌ی `.github` گاهی آپلود نمی‌شود): **Add file ← Create new file**، اسم: `.github/workflows/build-apk.yml`، محتوای فایل `build-apk.yml` را کامل بچسبان ← **Commit changes**.

## ساخت APK (هر بار)
1. تب **Actions ← Build Android APK ← Run workflow ← Run workflow**.
2. صبر کن (حدود ۲ تا ۱۰ دقیقه) تا ✅ سبز شود.
3. روی اجرا کلیک کن؛ پایین صفحه، بخش **Artifacts**:
   - **khaneyab-apk** ← داخلش `khaneyab-release.apk` است؛ همین را در بازار و مایکت آپلود کن.
   - **khaneyab-KEY-BACKUP** (فقط بار اول): فایل کلید امضا. این را دانلود و در چند جا نگه دار (فلش، تلگرام). بدون آن نمی‌توانی نسخه‌های بعدی را در فروشگاه به‌روز کنی.

## کلید امضا چطور کار می‌کند؟
- بار اول، خود ساخت‌کار یک کلید امضا با رمز تصادفی می‌سازد و داخل پوشه‌ی `keys` همین مخزن خصوصی ذخیره می‌کند. دفعه‌های بعد همان را به کار می‌برد، پس امضا همیشه ثابت می‌ماند.
- مخزن باید **Private** بماند و کسی را به آن اضافه نکنی.
- اگر از قبل کلید خودت را داری، فایل `.jks` را کنار `package.json` آپلود کن و فایل `signing.properties` (نمونه: `signing.properties.example`) را بساز؛ آن‌وقت از همان استفاده می‌شود. (یا اگر Secret ساخته‌ای: `KEYSTORE_BASE64`، `KEYSTORE_PASSWORD`، `KEY_ALIAS`، `KEY_PASSWORD`.)

## اگر خطا داد (❌)
روی اجرا کلیک کن، مرحله‌ی قرمز را باز کن و اسکرین‌شات آخر آن را بفرست.

## نسخه‌ی بعدی
- هر Run workflow شماره‌ی نسخه را خودکار بزرگ‌تر می‌کند.
- برای تغییر برنامه، فایل‌های داخل `www` را در مخزن عوض کن و دوباره Run workflow بزن.

## نکته‌ها
- این «نسخه‌ی فروشگاه» است: خرید اشتراک ندارد و ثبت آگهی رایگان است (`STORE_BUILD = true` در `www/index.html`).
- فونت و کتابخانه‌ها هنگام ساخت داخل خود APK گذاشته می‌شوند.
- نام بسته: `ir.divarmelki.app` (در `capacitor.config.json`). بعد از انتشار در فروشگاه قابل تغییر نیست.
